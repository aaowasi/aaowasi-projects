# OSCAL boundary

This repository targets OSCAL **1.2.3**, the current NIST reference release on 2026-09-17.

- `components/ccm-component.json` describes the reusable implementation component.
- Runtime assessment results are produced in the engine's normalized JSON first.
- A production assessment-result, SSP, profile, or POA&M export must be validated against the official NIST 1.2.3 JSON schema before release.
- ISO and AICPA control text is not copied into this public repository. Only owner-supplied identifiers and implementation statements are permitted.

Reference: <https://pages.nist.gov/OSCAL-Reference/models/v1.2.3/>
