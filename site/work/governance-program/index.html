Records & review

Use the shared initiative register. Fields: id, title, owner, status, reviewDate, notes, objective, budgetUSD, spentUSD, progressPercent, riskId. Records link by ID to related entities. Validate inputs, assign an owner and set a review date.

Connected workflow

Related workflows: policy-governance, regulatory-obligations, executive-risk. Reuse linked records in suite views rather than duplicating facts. The suite and specialist workspace use distinct import formats; export and reconcile records explicitly when crossing between them.

Acceptance & handover

Review required fields, supporting evidence, relationships and decision rationale. Export the suite JSON dataset for handover. This workflow organizes oversight metadata; external collection, recovery testing and regulatory interpretation require separately verified evidence.
